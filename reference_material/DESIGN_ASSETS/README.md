# DESIGN_ASSETS — Intake Instructions

**Put brand and design assets here**: logos, app icons, color palettes, fonts (with licenses), illustration sets, icon packs.

Notes:

- Only include assets you have the rights to use (store review checks IP rights).
- Prefer SVG or high-resolution PNG.
- If you have a palette, note hex codes in a small text file (e.g. `palette.txt`).
- Fonts must carry a license that permits app embedding.

Assets placed here are referenced from `docs/02_FRONTEND/` once the theme is implemented.
